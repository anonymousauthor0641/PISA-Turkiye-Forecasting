# Generated Outputs

This directory is reserved for files generated by the reproducibility pipeline.

The complete workflow creates the following subdirectories:

- `datasets/`: processed and generated datasets
- `tables/`: rolling backtesting, VIF, multi-seed, and forecasting results
- `figures/`: figures generated by the analysis scripts
- `logs/`: execution and unavailable-dependency logs

Run the complete workflow from the repository root:

```bash
python code/08_run_all.py
